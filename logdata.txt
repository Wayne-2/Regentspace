
From RegentSpace canva, The user creates an application through my UI builder in the canva, and the run build produces the JSON representation of the necessary data. That JSON will eventually be sent to a remote build server.

The build server will use Docker to provide an isolated Flutter/Android build environment. Inside the Docker image, I want to keep a Flutter project called:

`regentspace-builder`

This project is currently my base/template Flutter application, you can find it in './regentspace-builder'.

The eventual pipeline is intended to be:

User's visual builder from the  RegentSpace canva page
↓
Application JSON
↓
Build server
↓
Docker container
↓
regentspace-builder template
↓
JSON is interpreted/generated into Flutter code
↓
Flutter project is built
↓
APK
↓
Firebase Storage

Your job right now is **NOT to write the Dockerfile**.

Your first job is to thoroughly inspect the entire `regentspace-builder` project and determine how it should be converted into a reusable build template.
